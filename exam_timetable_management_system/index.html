Nine entities

1. departmenthas many students, courses, faculty
2. studentbelongs to a department
3. coursebelongs to a department
4. facultybelongs to a department
5. roombuilding, floor, capacity
6. time_slotsession and timings
7. examcourse + date + slot
8. invigilationexam + room + faculty
9. seat_allocationstudent + exam + room + seat
CREATE TABLE department (
  dept_id INT PRIMARY KEY, dept_name VARCHAR(50) NOT NULL UNIQUE);

CREATE TABLE student (
  reg_no VARCHAR(15) PRIMARY KEY CHECK (reg_no REGEXP '^RA[0-9]{13}$'), name VARCHAR(60) NOT NULL,
  semester INT NOT NULL, dept_id INT NOT NULL REFERENCES department(dept_id));

CREATE TABLE course (
  course_id INT PRIMARY KEY, code VARCHAR(10) UNIQUE NOT NULL,
  title VARCHAR(80) NOT NULL, semester INT NOT NULL,
  dept_id INT NOT NULL REFERENCES department(dept_id));

CREATE TABLE faculty (
  faculty_id INT PRIMARY KEY, name VARCHAR(60) NOT NULL,
  dept_id INT NOT NULL REFERENCES department(dept_id));

CREATE TABLE room (
  room_id INT PRIMARY KEY, room_name VARCHAR(20) UNIQUE NOT NULL,
  building VARCHAR(30) NOT NULL, floor INT NOT NULL, capacity INT NOT NULL);

CREATE TABLE time_slot (
  slot_id INT PRIMARY KEY, start_time TIME NOT NULL, end_time TIME NOT NULL);

CREATE TABLE exam (
  exam_id INT PRIMARY KEY AUTO_INCREMENT,
  course_id INT NOT NULL UNIQUE REFERENCES course(course_id),
  exam_date DATE NOT NULL,
  slot_id INT NOT NULL REFERENCES time_slot(slot_id));

CREATE TABLE invigilation (
  exam_id INT NOT NULL REFERENCES exam(exam_id),
  room_id INT NOT NULL REFERENCES room(room_id),
  faculty_id INT NOT NULL REFERENCES faculty(faculty_id),
  PRIMARY KEY (exam_id, room_id));

CREATE TABLE seat_allocation (
  exam_id INT NOT NULL REFERENCES exam(exam_id),
  reg_no VARCHAR(15) NOT NULL REFERENCES student(reg_no),
  room_id INT NOT NULL REFERENCES room(room_id),
  seat_no INT NOT NULL,
  PRIMARY KEY (exam_id, reg_no),
  UNIQUE (exam_id, room_id, seat_no));

The clash rules (one room or one invigilator per date and slot) need a trigger or application check, because date and slot live in exam while room and faculty live in invigilation. This demo runs those checks in JavaScript.

The query behind “Find my exam”:

SELECT c.code, c.title, e.exam_date, t.start_time, t.end_time,
       r.building, r.floor, r.room_name, s.seat_no
FROM seat_allocation s
JOIN exam e ON e.exam_id = s.exam_id
JOIN course c ON c.course_id = e.course_id
JOIN time_slot t ON t.slot_id = e.slot_id
JOIN room r ON r.room_id = s.room_id
WHERE s.reg_no = 'RA2411003010001'
ORDER BY e.exam_date, t.start_time;
